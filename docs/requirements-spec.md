# PSDリサイズ出力ツール 仕様書

> **注（内部リンク）**  
> 節番号（§）への内部リンク（例: `§15`）は、利用する Markdown レンダラ（GitHub、VS Code プレビュー、社内ビューア等）によって **アンカー名が異なる**場合がある。公開先に合わせ、必要に応じて目視でリンク先を確認する。

## 1. 目的

印刷所から提供されるPSDテンプレートのキャンバスサイズを基準に、ユーザーが指定した画像ファイルを縦横比を維持したまま内側に収め、制限付きの簡易PSDファイルとして出力する。

Photoshopを使用せずに動作することを前提とする。

**販売形態**は、Booth 等のデジタル販売プラットフォーム向けの**ビルド済みパッケージ**（[§15 配布・販売仕様](#15-配布販売仕様booth想定)）を想定する。

## 2. 想定ユーザー

- 印刷所ごとに異なるPSDテンプレートを扱うユーザー
- 入稿用画像をテンプレートサイズに合わせたいユーザー
- Photoshopを使わずに、簡易的なPSD形式の出力を行いたいユーザー
- デジタル販売版を購入し、導入ドキュメントに沿って導入する一般ユーザー

## 3. 対象範囲

### 3.1 対応する主な処理

- PSDテンプレートファイルの読み込み
- PSDテンプレートからキャンバス幅・高さを取得
- 印刷所マニュアルに基づくサイズ・解像度の上書き
- 入力画像の読み込み
- 入力画像の縦横比を維持したリサイズ
- テンプレートキャンバス内への中央配置
- 背景白の簡易PSD出力
- 手動による拡大率・配置の微調整

### 3.2 対象外

- Photoshop本体の自動操作
- テンプレートPSDのレイヤー内容の保持
- テンプレートPSD内のガイド、注釈、カット線、塗り足し線の再現
- スマートオブジェクト、テキストレイヤー、調整レイヤー、レイヤー効果の再現
- 完全なPhotoshop互換PSDの保証
- 複数ページTIFFの全ページ処理
- アニメーションGIFの全フレーム処理

## 4. 入力仕様

### 4.1 テンプレートPSD

印刷所から提供される実際のPSDファイルをテンプレートとして指定する。

テンプレートPSDから利用する情報は原則として以下に限定する。

- キャンバス幅
- キャンバス高さ
- 解像度（取得可能な場合）

テンプレートPSDのレイヤー内容は出力PSDには引き継がない。

### 4.2 入力画像

以下の形式を優先的に対応対象とする。

| 形式 | 対応方針 |
| --- | --- |
| PNG | 対応。透過は白背景に合成する |
| JPEG / JPG | 対応 |
| WebP | 対応。透過は白背景に合成する |
| GIF | 対応。アニメーションGIFは1フレーム目のみ使用する |
| TIFF / TIF | 対応。複数ページTIFFは1ページ目のみ使用する |
| BMP | 対応 |
| HEIC / HEIF | 可能であれば対応。環境依存があるためオプション扱い |

入力画像は最終的にRGBまたはRGBAのラスター画像として扱う。

### 4.3 座標系・寸法の単位

- キャンバスおよび入力画像の**幅・高さ**は、特に断りがない限り**ピクセル（px）**を正とする。テンプレートPSDからの値も、解釈上は**px ベース**である（PSD 内部表現の取り扱いは実装に委ねるが、**ユーザー向け表示は px** とする）。
- 印刷所マニュアルが**mm 等の物理寸法**のみの場合、**ユーザーが px に換算して入力**する。初版（v1）のツールは、**物理寸法から px を自動計算**する必須機能としない。将来、**物理寸法＋解像度から px を導出**する補助入力を[§13 将来拡張](#13-将来拡張)で追加できる余地を残す。

## 5. 出力仕様

### 5.1 出力形式

出力は制限付きの簡易PSDファイルとする。

想定するレイヤー構成は以下のいずれかとする。

- 背景白のキャンバスに入力画像を合成した単一レイヤー
- 背景白レイヤー + リサイズ済み画像レイヤー

実装時には、使用するPSD書き出しライブラリの互換性を確認した上で、より安定して開ける構成を採用する。

### 5.2 背景

背景は常に不透明の白とする。

- RGB値: `#FFFFFF`
- 入力画像の透過部分は白背景に合成する
- レターボックスによって発生する余白も白とする

### 5.3 サイズ

出力PSDの**キャンバス幅・高さ**（単位は **px**。[§4.3](#43-座標系寸法の単位)）は、**マニュアル上書きの有無**に着目した**要約**として次のとおり解釈する。

1. 印刷所マニュアルの上書き値（保存済み、または画面上で有効化した幅・高さ）
2. テンプレートPSDから取得した幅・高さ

上記の相対的な優先は、（2）に対して（1）が勝つ、という意味である。

**解像度（dpi/ppi）を含めた、ユーザー操作を含む完全な優先順位**は **[§8.2](#82-優先順位)** に従う。§5.3 は §8.2 の決定と矛盾する解釈をしてはならない。

### 5.4 解像度（dpi/ppi）とピクセル寸法

- **一次ソース**: 書き出し**ラスタのピクセル数**（出力キャンバス幅・高さ）は、**[§8.2](#82-優先順位)** で確定する **px** 幅・高さである。
- **dpi/ppi フィールド**: PSD に埋め込む**解像度メタデータ**、および**画面上の表記**に用いる。印刷では「**○dpi で W×H px**」のように併記されることが多いが、v1 では**幅・高さ (px) と dpi は原則独立**（ユーザーがそれぞれ意図した値に編集可能）とする。
- **dpi のみを変更**し、**幅・高さ (px) を変えない**操作が行われた場合、**ピクセル数は不変**とし、**解像度メタ・表示**のみを更新する想定（実装で PSD に解像度を埋められない場合は [§10.2](#102-警告) 等に委ねる）。
- **px を変えて dpi を変えない**操作も、同様に**原則独立**（ラスタ解像度とメタ解像度の**組み合わせ**に印刷上の不整合が出得る旨は、利用説明に注意書き可能）。

## 6. リサイズ仕様

### 6.1 基本方針

入力画像は、テンプレートキャンバスの内側に収まるようにリサイズする。

この方式を `contain` とする。

### 6.2 計算式

`canvasWidth` / `canvasHeight` は **[§8.2](#82-優先順位)** で定まった**出力キャンバス (px)** である。以下、同じ。

以下の値を使用する。

- `canvasWidth`: 出力キャンバス幅（px）
- `canvasHeight`: 出力キャンバス高さ（px）
- `imageWidth`: 入力画像幅（px）
- `imageHeight`: 入力画像高さ（px）

拡大率は以下で求める。

```text
scale = min(canvasWidth / imageWidth, canvasHeight / imageHeight)
```

リサイズ後のサイズは以下とする。

```text
resizedWidth = imageWidth * scale
resizedHeight = imageHeight * scale
```

中央配置の座標は以下とする。

```text
left = (canvasWidth - resizedWidth) / 2
top = (canvasHeight - resizedHeight) / 2
```

### 6.3 挙動

- 入力画像の縦横比は維持する
- 入力画像を歪ませない
- キャンバス比と画像比が異なる場合、上下または左右に白い余白が発生する
- 入力画像がキャンバスより小さい場合は拡大する
- 入力画像がキャンバスより大きい場合は縮小する

## 7. 手動調整仕様

### 7.1 拡大率（手動）の定義

手動の**拡大率**は、**§6.2 までを適用した直後**の状態、すなわち `contain` により得られた仮の `resizedWidth` / `resizedHeight` および中央配置（`left` / `top`）**に対する相対倍率**と定義する。**`1.0`（100%）**は、**自動 `contain` 直後**の見た目と等価である。

- UI 上の「拡大率」は、上記**相対倍率**の百分率表示（100% = 1.0）とする。これは**「キャンバス一辺に対する絶対倍率」**ではない。プレビュー表示・ラベルはこの定義に合わせ、実装注記（§9）と[§6](#6-リサイズ仕様)の計算式と**矛盾しない**こと。

### 7.2 座標

X / Y の手動補正は、§7.1 適用後の画像配置を基準にした**オフセット**（**ピクセル**、**右方向・下方向**を正）とする。座標系の原点は**キャンバス左上**（プレビューと書き出しで同一）とする。

### 7.3 操作

ユーザーは、自動配置後に少なくとも次を行える。

- 拡大率（§7.1）の調整
- X / Y オフセット（§7.2）の調整
- **中央揃え**（§7.2 のオフセットを **0** にし、画像を再びキャンバス中心に置く。実装の「中央に戻す」に相当）
- **contain 配置の再計算**（手動拡大率とオフセットを**破棄**し、**§6.2 から再適用**）

**v1 推奨（中央揃えと拡大率）**: 「中央に戻す」は**手動拡大率（§7.1）を変更せず**、**オフセットのみ**を 0 に戻す。`contain` 直後と**同一幾何**に戻す操作は、**本項の「contain 配置の再計算」**を用いる。拡大率も 100% まで戻す UI が別にある場合は**任意**（ユーザ説明上、**位置だけ直す**／**取り直す**の区別を明確にする）。[§11.2](#112-受け入れ基準簡易) の**回帰比較**（手動 100%・オフセット 0）を満たすには、スライダー等で**明示的に**指定するか、**contain 再配置**のあと**拡大率を触っていない**状態にする。中央戻し**単体**では拡大率が 100% とは限らない点に**注意**。

手動調整後も、**出力キャンバス寸法 (px)** は**変化しない**。

### 7.4 はみ出し（v1 の方針と未決定の切り分け）

手動拡大率・オフセットの結果、**リサイズ・変形後**の**入力画像**の有効範囲（外接矩形）が、キャンバス境界**外**にはみ出す場合（**幾何判定**。[§10.2](#102-警告)）:

- **v1**: 書き出し等を**必ずしもブロックせず、警告**を表示する（印刷所入稿上の**危険**の通知）。
- **はみ出しの禁止、書き出しブロック、自動クリップ**を行うかは **[§14 未決定事項](#14-未決定事項)** で決定。初版以降の最終ポリシーとする（「初期は警告」のみを v1 として固定）。

## 8. 印刷所マニュアル上書き仕様

### 8.1 上書き対象

印刷所ごとに以下の値を上書きできるようにする。

- 出力幅（px）
- 出力高さ（px）
- 解像度（dpi / ppi）

必要に応じて将来的に以下も追加できる設計とする。

- 印刷所名
- テンプレート種別
- 推奨カラーモード
- 注意事項

### 8.2 優先順位

サイズや解像度は以下の優先順位で決定する。

1. ユーザーが画面上で指定した値
2. 印刷所マニュアルの保存済み上書き値
3. テンプレートPSDから取得した値

#### 8.2.1 画面上の「上書き」有効化と 1. の扱い

- 画面（§9）に**マニュアル上書きのオン／オフ**（例: 「幅・高さ・解像度をマニュアルで上書きする」）を置く想定とする。
- **オフ**のとき: 幅・高さ・dpi の入力欄は**無効化**するか、**§8.2 の 1 には用いない**（表示だけの**ゴースト値**にしてはならない）。この状態での決定は **2 → 3**（**保存済み上書き**があればそれを使い、なければ**テンプレPSD**）のみと解釈する。読み手向け: **一時的な画面上の数値**は **1 扱いに含めない**。
- **オン**のとき: 有効な幅・高さ（および dpi）の**編集内容**を **1.** とする。未入力・無効な組み合わせのときの降り方（**1 をスキップ**して 2→3、等）は**実装で一貫**させ、[§10.1](#101-エラー) と矛盾しない範囲で定義する（例: 必須が空なら**エラー**、任意なら 2 へ、等）。

### 8.3 保存形式

上書き設定はJSONなどの構造化形式で保存する。

例:

```json
{
  "printerName": "example-printer",
  "templateName": "postcard",
  "width": 1748,
  "height": 1181,
  "dpi": 300
}
```

## 9. 画面仕様

初期実装では、以下の画面または操作領域を想定する。

### 9.1 ファイル指定

- テンプレートPSDの選択
- 入力画像の選択
- 出力先PSDの指定

### 9.2 テンプレート情報

- テンプレートから取得した幅・高さ
- テンプレートから取得した解像度
- 上書き後の出力幅・高さ
- 上書き後の解像度
- **マニュアル上書きのオン／オフ**（[§8.2.1](#821-画面上の上書き有効化と-1-の扱い) および有効化時の**確定**／無効化時の**2→3 のみ**の説明をヘルプまたはツールチップで補足してもよい）

### 9.3 プレビュー

- 白背景キャンバス
- リサイズ後の入力画像
- 余白の表示
- 手動調整後の位置とサイズ
- プレビュー枠の**アスペクト比**は、**出力キャンバス（§8.2 決定の幅:高さ）**に**追従**する。HTML 等の**固定比率モック**は、サンプル上の仮入れにすぎない（[ui-sample.html](ui-sample.html) 等）。

### 9.4 操作

- containで自動配置
- 拡大率調整
- X/Y位置調整
- 中央揃え
- PSD出力

**本番の UI** では「containで再配置」等、§7・§6 に紐づく操作を**有効**とする。画面モック上でボタンを `disabled` にしているのは、**挙動の非実装**を示すための例であり、仕様上は無効化を求めない。

## 10. エラー・警告仕様

### 10.1 エラー

以下の場合は処理を中断する。

- テンプレートPSDを読み込めない
- テンプレートPSDからキャンバスサイズを取得できない
- 入力画像を読み込めない
- 出力先にPSDを書き込めない
- 出力幅または高さが0以下

### 10.2 警告

以下の場合は警告を表示し、可能であれば処理を継続する。

- テンプレートPSDの解像度を取得できない
- 入力画像の解像度情報を取得できない
- HEIC / HEIFが現在の環境で読み込めない
- 複数ページTIFFの2ページ目以降を無視する
- アニメーションGIFの2フレーム目以降を無視する
- 手動調整（§7）の結果、**リサイズ・変形後**の**入力画像**の有効範囲（外接矩形）が、**出力キャンバス**（§8.2 の幅・高さ (px)）の外にはみ出す。
  - 判定は、スライダーの閾値等の**簡易**ルールではなく、**幾何（矩形とキャンバス境界）**に基づく。
  - **希少ケース**: 全面透過など、**アルファのみ**で**可視画素の外接矩形が幅または高さ 0**（**非可視**のみ）のとき、本項の**はみ出し警告**は**出さない**（はみ出しの対象外）。**「可視画素がない」**旨の**別警告**を出すかは**必須としない**（[§13 将来拡張](#13-将来拡張)で検討可）。
- カラープロファイルを維持できない

## 11. 品質・互換性要件

### 11.1 品質目標

- 出力PSDはPhotoshopや主要なPSD対応ソフトで開けることを目標とする
- ただし、完全なPhotoshop互換性は保証しない
- 出力PSDは簡易PSDであり、高度なレイヤー情報は含まない
- **リサンプリング**（`contain` および手動拡大率（§7）に伴う**縮小・拡大**）には、**高品質**と判断できる方式を用いる。使用する**アルゴリズム名**（Lanczos、Catmull-Rom、Bi-cubic 等）は実装で確定し、**縮小と拡大で同一の方式でよいか**は、品質比較のうえ[§14](#14-未決定事項)に記録してよい
- **γ（ガンマ）補正**や**線形色空間**上での厳密なリサンプリングは、**v1 では必須の品質目標に含めない**。将来、印刷所要件に応じ**線形**での処理を[§13](#13-将来拡張)等で検討する。テスト観点として、**境界**や**帯**が出る場合の**目視**をメモしてよい
- 透過画像は白背景に自然に合成する

### 11.2 受け入れ基準（簡易）

以下を**同じ入力・同じ上書き**に対し、少なくとも**手動**で**一回**通過確認できるとする（**§14 レイヤー案**のどれを採用するか**確定前**も、**いずれか**の構成で満たす前提）。

- **Adobe Photoshop**（対象バージョンは README 等に記す）で出力ファイルを**開き**、
  - **白背景**のキャンバス上に、入力画像内容が**意図した位置**で合成されている
  - **背景白**（§5.2）が**視認**できる
  - レイヤー数は、採用する §5.1 案に従い、**1 または 2**（+ 他にメタ専用等が出ないこと）
- **キャンバス**の幅・高さ (px) が、**§8.2 決定**と**一致**する（** dpi はメタ**であり、px と矛盾する**見かけ**があれば注意書き）
- **回帰比較**: `contain` のみの状態（§6）と、**手動拡大率 100%**・**オフセット 0**（§7.1 相当）で**幾何が一致**する。手順の注意点は **[§7.3](#73-操作) v1 推奨**を参照（「中央に戻す」**のみ**では拡大率が残る場合がある）。

## 12. 非機能要件

- Photoshopをインストールしていない環境で動作する
- Windows環境での利用を主対象とする
- 大きな印刷用画像でも処理できるよう、メモリ使用量に注意する
- エラー内容はユーザーが原因を判断できる表現にする
- 入力ファイルは原則として上書きしない
- 販売用ビルドは**同梱物・ライセンス表記**を揃え、**動作環境**を文書化できること（詳細は[§15](#15-配布販売仕様booth想定)）

- **物理寸法 (mm) ＋ dpi から px を一括導出**する UI や、**px と dpi の連動**（[§5.4](#54-解像度dpippiとピクセル寸法) の「原則独立」の例外）の要否

## 15. 配布・販売仕様（Booth想定）

本ツールの**小売想定**は、Booth 等における**デジタルダウンロード商品**とする。以下は「パターン1（ビルド済み＋同梱ドキュメント）」に揃えた配布形態の要件とする。プラットフォーム固有の**手数料・入金・税**は、出品時点の**各サービスの案内**に従う（本仕様の固定条件とはしない）。

### 15.1 配布形態

- **主な納品物**: 1本の**ZIP アーカイブ**（または同等の圧縮形式）
- **中身**:
  - **Windows 用ビルド済みの実行可能ファイル**と依存ファイル一式（**ポータブル版**：フォルダ内に .exe 等を配置し、そのまま展開して利用）
  - 補足として、**インストーラー**（.msi 等）を同梱または別商品にするかは[§14 未決定事項](#14-未決定事項)で決定する
- **ソースコード**は、商品に含めない方針とする（別途リポジトリや教材として配る場合は**ライセンスと説明文**を齟齬のない形で整理する）

### 15.2 同梱ドキュメント（必須）

パッケージ内に、少なくとも次を含む。

- **導入・起動手順**（3〜5ステップ程度でよい。初回の注意点、ウイルス対策ソフトの誤検知の可能性への短い注記を含めてもよい）
- **動作環境**（例: Windows 10 / 11、64bit、推奨メモリ。実装確定時に具体化する）
- **使い方の要約**（本仕様の要約、または抜粋。テンプレPSD、入力形式、上書き、背景白、contain 等）
- **利用規約（EULA）**または利用条件（**再配布禁止**、購入者の利用範囲、免責の枠組み。文言は**法的レビュー**の対象外だが、商品説明と矛盾しない内容とする）
- **サポート範囲**（対応窓口の有無、返金・不具合報告の受け方。未提供なら**仕様上の扱い**を明記）
- **サードパーティの著作権表示・ライセンス**（`NOTICE` / `ThirdPartyLicenses` 等。使用ライブラリの**再配布条件**に従う）
- **バージョン**（ファイル名や README にバージョン番号・日付を記載する）

### 15.3 利用者が期待できるもの

- **Python 等のインストールは不要**（同梱のランタイムまたは単一/少数の実行形態で完結）を**販売版の価値**とする
- 購入者は ZIP を展開し、手順に従って**すぐ起動**できる想定

### 15.4 更新配布

- 機能改修・不具合修正後は、**Booth 上の商品**を**新バージョンの配布**で更新する想定
- 商品ページの**版数・更新日**、ZIP 内**README の版数**を**一致**させ、購入者が入手版を識別できること

### 15.5 法務・コンプライアンス上の考慮（実装前に確認）

- 同梱する**全ての**オープンソース等ライブラリの**ライセンス**（**再配布、表記、ソース開示**等）に適合する
- **HEIC** 等、オプション要素を同梱する場合は、**同梱物由来のライセンス**を分離明記し、Booth パッケージに**含めない**選択も検討可能とする
- 出力**PSD ファイル形式**の利用に関し、**本ツールの範囲**では一般的な**ファイル入出力**に留まる。別途、利用するライブラリの**ライセンス条項**に従う

### 15.6 品質上の推奨（必須ではない）

- **コード署名**は Windows の SmartScreen 等の**警告軽減**に有効。費用・手続きの都合により、初版は**未署名＋導入文の注記**に留める判断も可能。採用可否は[§14](#14-未決定事項)で扱う
