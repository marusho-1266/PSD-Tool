# PSDリサイズ出力ツール — 利用手順（ユーザー向け）

印刷所向けの PSD テンプレートのキャンバスに合わせ、お持ちの画像を内側に収めたうえで、白背景の簡易 PSD として保存するアプリです。**Adobe Photoshop は不要**です。

---

## 1. 動作環境

- **対応 OS**: Windows 10 / 11
- **配布版（exe）**: `PSDResizeTool.exe` をそのまま実行できます（Python のインストールは不要です）。
- **開発版（ソースから実行）**: Python 3.10 以上を推奨します。詳細はリポジトリの `README.md` を参照してください。

---

## 2. アプリの起動

### 配布用 exe の場合

1. `PSDResizeTool.exe` をダブルクリックして起動します。
2. **初回起動時**、ウイルス対策ソフトのスキャンで数十秒かかることがあります。

### ソースから起動する場合

仮想環境の作成と依存パッケージのインストールのあと、`README.md` の「起動」に記載のとおり環境変数 `PYTHONPATH=src` を設定してから `python -m psd_tool` を実行します。

---

## 3. 基本の操作手順（最短）

1. **テンプレート PSD** の「参照…」から、印刷所などから入手した PSD を選びます。
2. **入力画像** の「参照…」から、配置したい画像（PNG／JPEG／WebP／GIF／TIFF／BMP など）を選びます。
3. 右側の **プレビュー** でレイアウトを確認します。
4. 必要なら **印刷所マニュアル上書き** で幅・高さ・解像度をマニュアル通りに合わせます（既定では上書きがオンです）。
5. 必要なら **配置・調整** で拡大率・位置を細かく調整します。
6. **出力先 (PSD)** で保存ファイル名と場所を指定します。
7. **「PSDとして書き出し」** を押します。
8. 完了のメッセージが表示されれば終了です。ステータスに「保存しました。」と表示されます。

---

## 4. 画面の主な項目

| 区分 | 内容 |
|------|------|
| **ファイル** | テンプレート PSD・入力画像・出力先 PSD の指定です。参照ダイアログの起点は、アプリ実行ファイルと同じフォルダ付近になります（exe の場合）。 |
| **印刷所マニュアル上書き** | 「幅・高さ・解像度をマニュアルで上書きする」がオンのとき、スピナーで指定したサイズ・DPI が出力に反映されます。オフにするとテンプレート側の解像度解釈などに合わせた挙動になります（詳細仕様が必要なら `requirements-spec.md` を参照してください）。 |
| **テンプレート情報** | PSD から読み取った幅・高さ・解像度、および上書き後の出力の目安です。 |
| **配置・調整** | **拡大率**：テンプレ内に収めたあとの大きさの比率。**位置 X / Y**：画像の位置。**containで再配置**：内側収めの初期配置に戻します。**中央に戻す**：オフセットだけリセットします。左上固定で拡大縮小するかどうかはチェックボックスで選べます。 |
| **プレビュー** | **テンプレート（点線・トンボ等）を重ねて表示**でガイドの重ね表示のオン／オフ。**ガイドの強さ**で半透明の強さ。**プレビュー表示 (%)** は見た目のズームのみで、書き出しの解像度には影響しません。ドラッグで画像を動かせます。 |

---

## 5. HEIC（iPhone 写真）について

環境により **HEIC／HEIF** はそのままでは開けないことがあります。画像を事前に JPEG／PNG に変換するか、利用環境で `pillow-heif` を追加インストールしてください（開発者・exe ビルド時向けの説明は `README.md` を参照）。

---

## 6. 注意事項（仕様の限界）

- 出力 PSD は **簡易形式**です。元テンプレートの複雑なレイヤー構造やスマートオブジェクトなどはそのまま引き継がれません。
- **ガイドの重ね表示** は位置合わせ用のプレビューだけで、書き出す PSD にテンプレの線画は **含まれません**。
- 画像がキャンバスからはみ出す場合、アプリから警告されることがあります。プレビューとメッセージを確認してください。

---

## 7. 困ったとき

- **書き出しボタンが効かない**: テンプレート PSD と入力画像の両方が指定されているか、出力先が指定されているか確認してください。
- **exe が起動しない／遅い**: セキュリティソフトによる検査やブロックがあり得ます。許可リストへの登録や一時的な無効化を検討してください（自己責任で行ってください）。

より詳しい技術仕様は `docs/requirements-spec.md` を参照してください。
